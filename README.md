# Agent AI Nano

Nano is a personal AI agent built with JavaScript and React Ink.

> **Status:** 🚧 This project is currently under development.

## Features

- Personal AI agent
- Built with JavaScript
- Terminal interface powered by React Ink
- Currently supports the Google provider

## Installation

Clone the repository:

```bash
git clone <repository-url>
cd agent-ai-nano
```

Install the dependencies:

```bash
npm install
```

## Before You Start

Create a `config/settings.json` file with the following content:

```json
{
  "username": "arip",
  "provider": "google",
  "model": "gemini-3.1-flash-lite",
  "apiKey": "YOUR_API_KEY"
}
```

Replace `"YOUR_API_KEY"` with your Google Gemini API key.

## Usage

Start Nano:

```bash
npm run nano
```
